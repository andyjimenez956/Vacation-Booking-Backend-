# Vacation Booking Backend

## 🚀 Overview
This project provides a RESTful backend for a vacation booking application. It includes endpoints to manage vacations, excursions, carts, orders, and checkout logic.

## 🧠 Features
- Create / Read / Update / Delete vacations & excursions  
- Manage shopping cart and checkout flow  
- Input validation and error handling  
- Uses Spring Boot, JPA, and MySQL

## 🛠 Tech Stack
- Java 17
- Spring Boot
- MySQL
- Maven
- JPA / Hibernate
- Swagger (if enabled)
